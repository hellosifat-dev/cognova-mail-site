Architecture

Proven mail servers, a modern control plane.

Cognova Mail does not reinvent SMTP. It puts a clean, secure dashboard and API on top of the mail stack that already runs much of the internet.

Self-hosted first

Core features never depend on a Cognova-operated service: no mandatory account, activation, relay or telemetry.

Isolation by default

A guessed or stale workspace ID cannot cross boundaries. Every API and mail action is authorized on the server.

Open source end to end

Licensed AGPL-3.0-only. No artificial feature paywalls in the software.

No open relay, ever

Separate policies for the public MX and authenticated submission, with Rspamd scanning both paths.
